# THE MEDIA PIRATE

Адаптивная статическая медиатека для GitHub Pages, обычного браузера и Media Station X. Сайт не требует сборки, сервера или ключей API. Интерфейс по умолчанию на русском.

## Возможности

- Главная витрина и локальные подборки фильмов, сериалов и аниме.
- Поиск по демо-каталогу и доступному публичному каталогу AniLibria API v3.
- Подробные карточки, избранное, история, настройки и обработка пустого/недоступного каталога.
- Открытие HDRezka, LostFilm, Filmix и AniLibria отдельной вкладкой.
- Клавиатурная и пультовая навигация: стрелки, OK/Enter, Escape/Backspace.
- Модуль HTML5-плеера для разрешённых прямых источников; пользовательские сервисы намеренно не извлекаются.
- Пути к локальным ресурсам относительные; подходит для размещения в подпапке репозитория.

## Источники и ограничения

Локальная витрина — демонстрационная подборка метаданных и постеров TMDB Image CDN, а не подтверждение наличия контента у сторонних сервисов. Обложки грузятся с сети; при недоступности показывается текстовый плейсхолдер.

Из четырёх адаптеров только AniLibria подключена к документированному публичному каталогу API v3 для поиска и обновлений. API каталога не считается разрешением на скачивание или встроенное воспроизведение видеопотоков. CORS/доступность API могут меняться. HDRezka, LostFilm и Filmix в этой клиентской версии работают как безопасные ссылки на сайты: не обнаружен проверенный официальный публичный API с гарантированным доступом из браузера. Для полноценной унифицированной выдачи потребуется серверный адаптер, который использует только разрешённые сервисом методы, не хранит пользовательские пароли без необходимости и не обходит DRM/платный доступ. На GitHub Pages такого сервера нет.

HTML5-плеер реализован для прямого разрешённого медиа URL и сохраняет позицию. Ссылки сервисов не притворяются прямыми видеопотоками. Встроенное воспроизведение или субтитры недоступны, пока поставщик не предоставит разрешённый совместимый URL/треки.

Хранилище localStorage не синхронизируется между устройствами. Если оно отключено или повреждено, приложение запускается с пустым состоянием.

## Запуск локально

ES modules требуют HTTP, поэтому откройте папку через любой локальный статический сервер, например `python -m http.server 8000`, затем перейдите на `http://localhost:8000`. Сборка не нужна.

## GitHub Pages

1. Создайте публичный GitHub репозиторий с именем `the-media-pirate` и отправьте содержимое этой папки в ветку `main` в корень репозитория.
2. В Settings → Pages задайте Build and deployment → Deploy from a branch, ветка `main`, папка `/(root)`.
3. После публикации откройте `https://USERNAME.github.io/the-media-pirate/`.

Главная страница не использует абсолютные ссылки на локальные CSS/JS и поэтому корректно загружается в подпапке. Сторонние постеры/API зависят от сети и политики CORS.
