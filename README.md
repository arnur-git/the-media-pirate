# THE MEDIA PIRATE

Адаптивная статическая медиатека для GitHub Pages, браузеров и Media Station X. Сборка и сервер для главной страницы не нужны.

## Возможности

- Каталоги, поиск, карточки тайтлов, избранное, история и настройки.
- Живые каталог и поиск AniLibria через документированный API v1.
- Выбор эпизода и качества прямого HLS-видеопотока AniLibria, если API вернул поток; воспроизведение через HTML5 `<video>`.
- HTML5-плеер для пользовательских прямых HTTP(S) видео-ссылок.
- Навигация с клавиатуры и пульта: стрелки, Enter/OK, Escape/Back.
- Сохранение локальных данных и позиции воспроизведения в `localStorage`.
- Относительные пути для публикации в подпапке репозитория.

## Источники видео и ограничения

AniLibria использует актуальный API v1 (`https://api.anilibria.app/api/v1`), описанный в [официальной документации](https://api.anilibria.app/api/docs/v1/). API возвращает эпизоды и поля HLS-качества; приложение показывает выбор эпизода и прямые потоки, если они доступны. CORS и воспроизведение HLS зависят от доступности API и возможностей браузера. Safari и некоторые ТВ-браузеры воспроизводят HLS напрямую; браузеры без нативной поддержки HLS могут сообщить о неподдерживаемом формате.

HDRezka и Filmix не подключены как видеопотоки: доступные сторонние парсеры и внутренние API требуют обхода защит, авторизации или нестабильных частных интерфейсов. Приложение их не использует и не запрашивает пароли, коды устройств или токены. LostFilm публикует RSS/торрент-данные, а не прямые видеопотоки; персональные RSS-ссылки и скачивание торрентов здесь не используются. Эти адаптеры не показывают веб-сайты как фиктивные «видеоисточники».

Пользовательский HTML5-плеер принимает прямой HTTP(S) URL на видеофайл или поток, если у пользователя есть право доступа к источнику. Он не извлекает ссылки со страниц сторонних сервисов и не обходит DRM. Поддержка контейнеров, HLS, субтитров и полноэкранного режима определяется браузером и самим источником.

Витрина содержит демонстрационные карточки; это не заявление о наличии соответствующего видео у какого-либо провайдера. Постеры каталога AniLibria поступают из ответа API.

## Запуск локально

Откройте проект через любой статический HTTP-сервер, например `python -m http.server 8000`, затем перейдите на `http://localhost:8000`. ES modules не работают надёжно через `file://`.

## Публикация на GitHub Pages

В Settings → Pages выберите публикацию из ветки `main`, папка `/(root)`. Сайт проекта доступен по адресу `https://arnur-git.github.io/the-media-pirate/`.

